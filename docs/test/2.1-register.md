## 一、功能概述

实现学生/教师分流注册：访客凭学号（学生）或工号（教师）+ 邮箱 + 密码注册，系统校验身份格式、全局唯一性、密码强度，密码以 bcrypt 哈希存储，**绝不保存明文**。

接口：`POST /api/v1/auth/register`（201 成功 / 409 冲突 / 422 校验失败）

### 5.4 发现与处置

1. **E-06（已修复 ✅）**：原 FAIL——注册接口接受 10MB 超大 body（无请求体上限，DoS 风险面）。
   - **修复**：新增 `app/shared/body_limit.py`（ASGI 流式计数中间件：包装 receive 边转发边计数并缓存，超限不调下游直接发 `413 {"detail":"request body too large"}`；不依赖 Content-Length，chunked 同样拦截；`MAX_BODY_BYTES = 1 MiB` 模块常量）
   - **挂载**：`app/main.py` create_app 全局挂载（后续 2.4 提问等接口天然受保护）
   - **测试**：`tests/test_body_limit.py` 5 条（413×Content-Length 形态、413×chunked 形态、小 body 重放到路由、/health 透传、恰好 1MB 边界）**不标 integration，进 CI**；另在注册接口集成测试补 1 条"小 body 经中间件重放后正常 201"
   - **复测**：真实服务 10MB body → 413 ✓，服务存活；pytest 44 passed、ruff 0、mypy strict 0
2. **R-15（不修，留约定）**：XSS 邮箱 JSON 回显无执行面，后端存储原文是正确行为。**约定：前端渲染时必须转义（React/TS 默认转义）**。另：暴力测试方案 R-15 与 Q-07 的 XSS 判定标准已统一为"前端转义"口径。
3. **多余字段静默忽略（不修，留约定）**：Pydantic 默认忽略未定义字段。**约定：自 2.2 登录起，新 schema 统一 `model_config = ConfigDict(extra="forbid")`**，2.1 的 RegisterRequest 在 2.2 迭代内一并补齐。
