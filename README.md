# CampusOverflow
本学期以一个贯穿整个学期的、可运行、可演进、可部署的真实软件项目——CampusOverflow校园问答平台——作为载体，引导学生在做中学、在迭代中悟、在交付中长。 CampusOverflow主要解决通用型问答平台Stack Overflow 并不能完全满足高校场景下的特定需求的痛点：学生需要按课程、按教师、按班级组织的细分知识社区；教师需要将答疑工作沉淀为可复用的教学资产；学院需要量化学生学习参与度作为过程评价依据。 CampusOverflow既具备标准问答平台的完整功能(提问、回答、投票、标签、声誉)，又深度融合校园场景的独特要素(课程关联、师生认证、班级圈、悬赏积分、学风画像)。
